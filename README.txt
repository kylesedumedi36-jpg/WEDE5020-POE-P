Project Overview
Project Overview

The purpose of this project is to design and develop a professional, user-friendly website that presents information about Gina Daniel’s research on NPEs (Not Parent Expected). The website will provide visitors with clear and well-organised information about the research topic while demonstrating my ability to plan, structure and develop a website using modern web development principles.

The project will be completed in three stages. The first stage will focus on planning the website, conducting relevant research, gathering suitable content and assets, creating the basic HTML structure, and organising the project files. The second stage will focus on using CSS to improve the visual appearance, layout, responsiveness and overall user experience of the website. The final stage will introduce JavaScript functionality and interactive features to make the website more engaging and functional.

Purpose of the Project

The main purpose of the website is to educate and inform visitors about the research topic in a clear, accessible and professional manner. The website will organise the information into logical sections so that users can easily find and understand the content.

A further purpose is to demonstrate my practical web development skills, including:

-Planning and designing a website.
-Structuring content using HTML.
-Applying CSS for layout and visual design.
-Using JavaScript to provide interactive functionality.
-Creating a responsive website suitable for different screen sizes.
-Applying basic SEO principles.
-Organising website files and digital assets correctly.
-Using credible sources and applying consistent academic referencing.

Project Objectives

By the end of the project, I aim to have developed a website that:

1. Provides relevant and reliable information about the selected research topic.
2. Has a clear and logical navigation structure.
3. Uses appropriate headings, sections, images and other visual assets.
4. Is visually appealing and easy to use.
5. Works effectively on different screen sizes.
6. Includes interactive functionality where appropriate.
7. Uses appropriate academic sources and consistent referencing.
8. Demonstrates the web development skills learned throughout the project.

Target Audience

The website is primarily aimed at students, researchers and members of the general public who are interested in learning about the research topic. The content will therefore be presented in language that is informative but still understandable to users who may not have prior knowledge of the subject.

Expected Outcome

The final outcome will be a fully functional, responsive and professionally structured website that combines researched content with appropriate design and functionality. The project will demonstrate my ability to take a website from the initial planning and research stage through to the development of a complete online presence.

The website is developed using HTML.
