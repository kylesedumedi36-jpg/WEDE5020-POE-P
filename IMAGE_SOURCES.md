# Photo sources

The website uses food photographs hosted by Unsplash. An internet connection is needed to show these pictures. The photos are used as examples for this student website.

The current website uses these Unsplash photo collections:

- Bread and loaves: https://unsplash.com/s/photos/bread-loaf
- Cakes: https://unsplash.com/s/photos/celebration-cake
- Pastries: https://unsplash.com/s/photos/croissant-pastry
- Cookies and cupcakes: https://unsplash.com/s/photos/cookies-cupcakes
- Coffee and hot chocolate: https://unsplash.com/s/photos/coffee-hot-chocolate

The image links are written in `menu.html` and `js/script.js`. Please check the image licence and the original photographer details before using the pictures for a real business.
