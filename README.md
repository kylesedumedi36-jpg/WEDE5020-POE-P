# Ora's Bakery Website

This is a small website for Ora's Bakery. It has separate pages for the home page, the bakery story, the menu, the gallery, order enquiries and contact details.

## How to open the website

1. Unzip the project folder.
2. Open the `website` folder.
3. Double-click `index.html` to open the home page in a browser.
4. Keep the `css`, `js` and `images` folders in the same place. The website needs these folders to work properly.

The food photographs are loaded from the internet, so an internet connection is needed to see them.

## Website pages

- `index.html` – the home page.
- `about.html` – information about the bakery.
- `menu.html` – the menu and prices.
- `gallery.html` – food photographs. Choose a collection to see more pictures.
- `enquiry.html` – a form for asking about an order.
- `contact.html` – contact details and a message form.

## How the website works

- The menu search box helps visitors find products.
- The Gallery page has different food collections. Visitors can click a picture to make it bigger.
- When a visitor clicks an "Enquire about" link on the menu, the enquiry page opens with a product already selected.
- The enquiry page shows three example photographs for the selected product type.
- The enquiry form checks the required information and calculates an estimated total.
- The contact form checks the details and opens the visitor's email application.

## Important note

This is a front-end student project. It does not save orders in a database or send orders to the bakery automatically. The price shown by the calculator is only an estimate. The bakery must confirm the order and final price.
